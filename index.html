Optional: use your own token instead ›

Normally nothing to do: the sync token arrives encrypted inside this device's data and connects automatically. A token pasted here overrides it on this device.

  1. Open github.com/settings/personal-access-tokens/new (signed in as rav-pawar).
  2. Token name: e.g. “Life HQ sync – this phone”. Expiration: 1 year (it can only touch the inbox; renew it here when it expires).
  3. Resource owner: rav-pawar.
  4. Repository access: Only select repositories → rav-pawar/life-hq-inbox.
  5. Permissions → Repository permissions → Issues: Read and write. Leave everything else at No access (Metadata: Read-only is added automatically).
  6. Generate token, copy it (starts with github_pat_), paste it above, tap Save token, then Test sync.

The token is stored on this device encrypted with a non-extractable key (best effort). Remove it here if the device is lost, and revoke it on GitHub.
