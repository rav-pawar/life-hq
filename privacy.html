Privacy policy: Daily briefing / Life HQ

Last updated: October 20, 2026

What this app is

Daily briefing / Life HQ is a personal app. It is built and used only by its owner, for the owner's own Google account. It is not offered to the public and has no other users.

What Google data it accesses

  • Google Tasks: read-only. Tasks are read to show the owner's to-do list. The app never creates, changes or deletes tasks.
  • Gmail: the owner's own messages are read to find reminders such as bills, due dates and deliveries.
  • Google Calendar: the owner's own upcoming events are read to show the day's schedule.

How the data is used

The data is used only to build a private personal dashboard and reminders for the owner. Before it is published, the dashboard data is encrypted so that only the owner's own enrolled devices can read it.

Sharing

Data from Google is not sold, not shared with anyone, not used for advertising and not used to train models. It is used only for the owner's own personal use.

Storage and security

Data is stored encrypted and kept only as long as the owner needs it for the dashboard. Access tokens are kept private and are never published.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions, use the developer support email shown on this app's Google sign-in consent screen.
